# Forensic Web Demo Prototype

一个可直接打开的前端交互原型（无构建步骤），用于验证“证据可追溯”演示流程。

## 快速运行

```bash
cd demo/forensic-web
python -m http.server 8000
```

浏览器访问：`http://localhost:8000`

> 也可以直接双击 `index.html` 打开；若需要本地文件上传/下载行为更稳定，建议用本地 HTTP 服务。

## 已实现交互

- 四页导航：案件列表 / 案件详情 / 转写复核 / 审计与导出
- 音频上传后计算 `SHA-256`，写入证据信息与审计时间线
- 机器初稿分段点击跳转播放（基于上传音频）
- 文本修订 + 修改原因 + diff 预览 + 审计事件
- 导出结构化 JSON 证据包（原型版）
- 可视化：
  - 案件状态分布条形可视化（待复核 / 已确认 / 已导出）
  - 转写时间轴画布（风险片段高亮、播放指针、点击跳转）
  - “上一处/下一处风险”快捷跳转

## 测试步骤（手工验收）

1. 启动服务并打开页面。  
2. 在「案件详情」上传一个音频文件，验证：
   - 出现“证据固化成功”面板；
   - 显示 SHA-256；
   - 审计时间线新增 `audio_uploaded` / `hash_generated` / `transcription_completed`。  
3. 进入「转写复核」，验证可视化：
   - 时间轴出现蓝/红片段；
   - 点击时间轴可跳转到对应片段；
   - 点击“上一处风险/下一处风险”可在风险片段间切换；
   - 播放音频时白色播放指针会移动。  
4. 修改一段文本并选择修改原因后保存，验证：
   - diff 预览正确；
   - 提示“已生成审计记录”；
   - 状态变为“已形成确认稿”。  
5. 在「审计与导出」点击“标记已导出”，验证：
   - 状态变为“证据包已导出”；
   - 审计时间线新增 `evidence_exported`。  
6. 点击“导出结构化 JSON”，验证浏览器下载文件成功，且 JSON 内包含 `evidence` / `segments` / `edits` / `audit` 字段。
