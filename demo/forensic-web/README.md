# Forensic Web Demo Prototype

一个可直接打开的前端交互原型（无构建步骤），用于演示“证据可追溯”的案件工作台流程。

当前版本不是“全局四页切换”，而是：

1. 先从「案件中心」选择案件
2. 进入「当前案件工作台」
3. 在案件详情里查看多条语音证据
4. 通过案件内的四阶段入口操作当前证据

## 快速运行

```bash
cd demo/forensic-web
python -m http.server 8000
```

浏览器访问：`http://localhost:8000`

如果本机没有可用的 `python` 命令，也可以使用任意本地静态 HTTP 服务。

## 你会看到什么

启动页面后，可以直接体验三条并行线：

- 案件主线：从案件中心进入案件工作台
- 材料主线：上传案件情况分析文件，决定是否纳入参考
- 证据主线：上传语音证据，进入阶段化处理和导出

## 当前交互结构

- 全局导航仅保留：
  - `案件中心`
  - `当前案件工作台`
- 案件工作台包含：
  - 案件基础信息
  - 案件情况分析文件
  - 新增语音证据
  - 多条语音证据列表
  - 案件内四阶段入口
  - 当前证据对应的阶段内容区
  - 案件最近活动

## 当前已实现能力

- 证据列表支持多条语音证据，默认隐藏已归档记录
- 证据列表通过 `查看` 切换当前证据上下文
- 案件情况分析文件支持 PDF / Word / TXT 等格式上传
- 分析文件上传后生成水印记录，不可删除，只能切换是否纳入参考
- 原始证据不可删除，仅支持归档
- 证据归档后写入 `evidence_archived` 审计事件
- 四阶段入口按当前证据状态控制可访问范围：
  - `原始证据已固化`
  - `自动转写完成`
  - `待人工复核`
  - `已形成确认稿`
- 人工复核支持：
  - 音频-文本联动
  - 风险片段高亮
  - 按已选分析材料展示风险提示依据
  - 明确展示“命中哪份材料 / 哪条规则 / 为什么提示”
  - 时间轴跳转
  - 修改原因选择
  - diff 预览
  - 提交后形成确认稿
- 确认稿支持：
  - 导出结构化 JSON
  - 标记已导出
  - 查看审计摘要
  - 查看风险提示依据摘要

## 当前页面的操作含义

- `查看`
  - 切换当前证据
  - 阶段入口和内容区会自动切换到该证据的当前阶段
- `归档`
  - 不删除证据
  - 仅将证据标记为归档并默认从列表隐藏
- `选为参考 / 取消参考`
  - 控制某份案件情况分析文件是否参与后续语音风险提示
- `标记已导出`
  - 不是真实上传动作
  - 用于演示导出事件写入审计链

   - 默认不自动纳入参考

   - Step 2 / Step 3 的风险提示依据同步变化
   - 能看到命中的材料、规则和原因说明
5. 在证据列表点击不同证据的「查看」，验证：
   - 当前证据切换成功
   - 阶段入口和内容区跟随当前证据刷新
6. 进入 `CASE-2026-003`，验证 Step 3 / Step 4 按钮不可点，且页面提示尚未选用分析材料。
7. 进入 `CASE-2026-004`，验证仅 Step 1 可进入。

   - 新增证据记录
   - 当前阶段变为“待人工复核”
9. 在 Step 3 修改文本并提交，验证：
   - 进入 Step 4

10. 在 Step 4 点击“导出结构化 JSON”，验证浏览器下载成功，且 JSON 包含参考材料字段和详细风险依据链。

## 常见问题

### 为什么分析文件上传后不能删除？

因为这个 Demo 要强调“案件背景材料也属于证据链的一部分”。上传后保留水印记录，只能决定是否把它纳入当前语音分析参考。

### 为什么风险提示有时只有基础标签，没有详细依据？

如果案件中还没有“已选参考材料”，系统会退回到基础标签和关键词规则，并明确提示“尚未选用分析材料”。

### 为什么有的阶段按钮点不了？

阶段入口受当前证据状态控制。比如只到 `自动转写完成` 的证据，不允许直接进入 `待人工复核` 或 `已形成确认稿`。

### 导出的 JSON 里最重要的字段是什么？

如果要展示“风险提示不是黑盒”，最重要的是：

- `selected_reference_materials`
- `risk_reference_context.findings`
- `risk_reference_context.findings[].hits[].rule`
- `risk_reference_context.findings[].hits[].reason`

## 已知限制

- 不做真实 PDF / Word 解析
- 不做真实 ASR 推理
- 风险提示依据链仍然是前端模拟逻辑
- 音频上传后的转写结果是演示数据模板，不是真实识别输出
